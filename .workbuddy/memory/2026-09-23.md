**分析结论（项目架构现状，v0.2.0）**

- 纯前端 PWA，无服务端，数据全部存 IndexedDB（Dexie 4），库名 `suptrack-v12`，8 张表一次性 version(1) 建好。
- 严格 5 层单向依赖：入口外壳 → 布局/UI 组件 → hooks+stores → services+repositories → db/domain。
- 横切层 `utils/*` 为纯函数判定核心：只 import types/constants，不 import db/React，因此可纯函数单测。
  - 其中 `utils/dayState` 是判定核心（四态：已服 > 停用 > 休息 > 待服），今日页与日历页共用同一份判定。
- 跨标签页一致性链路：写操作 → `utils/broadcast::publishDataChange` 广播 → 其它标签页 `stores/dataVersion` 自增 → `useLiveQuery` 重查；同标签页由 Dexie liveQuery 自动处理。
- 余量联动唯一入口：`services/stockAdjust::applyStockDelta`（打卡/追加/补录/撤销/改量全走它，保证加减对称）。
- 服务层写入口统一 `parseOrThrow`（Zod）校验 + `db.transaction` 事务边界。
